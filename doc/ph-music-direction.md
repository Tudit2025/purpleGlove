# 《紫手套》气质与配乐候选

整理日期：2026-11-02。

剧情依据：`performance-edit/00—07` 当前演出稿、`ph-revised.md` 的世界观与人物动机，以及 `ph-audio-library.md` 的既有声音方案。候选来自作者／发行方页面，已核对公开的编制、情绪、循环版本及授权说明；未逐首完成听觉审听或游戏内混音测试。下文的场景对应与音乐取舍是本项目的设计建议。

## 整体气质

一句话定位：**雨夜里，一名年轻核验人在封闭的烛光工作间，逐渐看清师父的过错与权力的交易，最后必须为自己的签名负责。**

| 层面 | 关键词 | 故事中的依据 | 音乐方向 |
|---|---|---|---|
| 空间与触感 | 雨夜、烛光、旧木、厚纸、墨迹、封蜡 | 全夜留在工作间，依靠文书和门口交接推进 | 小编制、稀疏织体，留出纸声与门声的位置 |
| 外部压力 | 封闭、等待、被注视、礼貌的威胁 | 书记官催促归还原件，卡拉法要求淡化换版 | 低音持续音、缓慢不协和、少量重复动机 |
| 调查体验 | 专注、辨伪、抽丝剥茧、迟疑 | 密文读得通仍须核验签名、版次和来源 | 稳定而不催促的节奏，长时间聆听不疲劳 |
| 政治处境 | 体面、隐瞒、交易、程序、责任 | 三方各自索取原件与担保，手续影响师父命运 | 克制、冷静、悬而未决的和声 |
| 师徒关系 | 信任、裂痕、羞愧、牵挂、独立 | 卢卡发现师父明知有假仍然签字 | 少量独奏弦乐，旋律在自白揭晓后才更清晰 |
| 尾声 | 清晨、疲惫、余悔、有限希望、未竟之事 | 救回师父仍须接受问责；交出证据也未必能立即团聚 | 保留余味，让重逢有温度，让失败保持沉静 |

最值得保留的六个核心词：**烛光、封闭、暗流、辨伪、愧疚、微光。**

建议以低音弦乐、维奥尔琴／古提琴、稀疏鲁特琴或竖琴作为音色方向；空气感持续音仅作底层。世界观是架空城邦，可容纳少量现代配器，但应保持室内、近距离的听感。音乐不宜提前告诉玩家某个角色必然有罪。

## 按剧情安排音乐

| 段落 | 建议处理 |
|---|---|
| 第零幕：门槛 | 先让雨与门外空间成立，进入工作间时再引入极轻的音乐 |
| 第一、二幕：学习与查证 | 保持稳定、低密度的底乐；完成一个密码不必立刻播放强烈胜利旋律 |
| 第三幕：各方接连来访 | 增加低弦张力；换访客时让关门、锁扣和重新开窗的声音清楚可辨，音乐可跨对话连续 |
| 第四幕：师父自白 | 在明文实际揭晓以后引入情感旋律，避免提前预告秘密 |
| 第五幕：落笔与交卷 | 音乐表现沉重选择；节奏仍给玩家足够阅读空间。摇铃与文件转出可以逐步减薄音乐 |
| 开门 | 重逢中保留迟疑与疲惫，最后开门时才稍微释放和声 |
| 缺页 | 可沿用师徒主题，减少温暖声部；师父沉默处允许音乐退出 |
| 真相易手 | 收束在尚未解决的和声与等待感，师父仍留候核验 |
| 背书 | 保留低弦和短小余音，呈现后悔与不确定；剧情没有确认师父死亡 |

建议先做四类音乐状态：桌面调查、来访压力、自白与选择、尾声。允许曲间出现只有雨声和操作声的空隙。各幕由叙事推进时间，音乐不需要持续制造真实倒计时感。
