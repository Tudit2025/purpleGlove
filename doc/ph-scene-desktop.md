# 《紫手套》桌面场景与固定机位方案

本方案配合《紫手套》修订脚本。视觉目标为《邪恶铭刻》式的低多边形三维空间、明显的像素采样、昏暗但可读的局部照明，以及以实物承载操作的界面。场景、人物和道具内容使用《紫手套》自身设定。

本次模拟画面选取第一幕：卢卡刚打开师父留下的第一封信。只展示桌面主机位，不把不同机位拼成展示板。图像是模拟实机的视觉概念稿，尚不是引擎运行截图。

## 1. 三个机位

### 主机位：坐在桌前

- 固定第一人称，视线向下约三十五度，桌面占画面约四分之三至五分之四。
- 桌子近端压住画面下沿，物件以真实透视排列；避免垂直俯视造成二维棋盘感。
- 画面上方只保留少量墙面、门的一部分与投递口，给出桌外空间的深度。
- 左侧放查阅资料，中央处理当前问题，右侧组织交接。玩家不必每幕重新寻找同一种工具。
- 提起信纸、把书拉近、展开两页，均由物件移动完成，镜头仍留在主机位。

### 副机位：抬头看门

- 保持玩家座位不变，镜头沿预设路径抬头，必要时略向右转。构图集中于门、门缝光、投递口。
- 用于听敲门、隔门交谈、确认送件人的声音，以及观察投递动作。
- 不开放自由环顾、走向门口或额外窗边机位。窗户可以在场景中提供冷色环境光，不承担必须转头查找的信息。
- 敲门时先给声音，让玩家决定抬头；普通收件不反复强制切镜头。发生正式交接时可以有一次短暂的固定过渡。

### 左侧机位：五层资料书架

- 玩家留在原座位，按 **A** 转向左侧书架；五层从上到下对应第一幕至第五幕。
- 幕结束时，把该幕的密文、工作纸、信封等阶段性资料归成一份卷宗，放在对应层。未开始的幕不提前显示资料。
- 卷宗沿用场景物体的悬停抽出反馈；点击后把该幕资料放回桌面，同时将桌上正在展示的另一幕资料收回其对应层。资料内容和批注保留，参考书、笔记本与笔具常驻桌面。
- **W** 看门口，**S / D** 回桌面；左下角仅保留小号黑边像素“WASD 切换视角”提示。检视物件期间先用 Esc 或 X 放回，再切换视角。
- 书架与卷宗不显示文字说明，按固定层序组织资料；书架侧面安装一只小烛台。
- 书架与卷宗沿用桌面家具的灯光层、材质和阴影处理，不设独立补光。侧面烛台使用与桌面烛台相同的光源配置。
- 座位后方补齐灰泥墙与木梁，复用房间其他墙面的材质、米制 UV 和像素颗粒大小，并与侧墙、顶面闭合。

第零幕的门外画面是入场序幕，不作为正篇的可切换机位。

## 2. 桌面保留八组功能物件

| 位置 | 物件 | 承担的功能 | 拟物操作 |
|---|---|---|---|
| 正中央 | 皮质书写垫、当前信纸、答题纸 | 当前谜题与玩家的回复；预留两页并排比对的位置 | 拾起、翻面、移到烛光侧面；输入的字直接落在答题纸上 |
| 左前 | 师父的旧笔记本 | 密码教案与过往日志 | 翻页、用书签定位、拉近阅读；不生成新日志 |
| 左后 | 两本不同版本的《祷文集》 | 书本密码与版本比较 | 拉出其中一本，打开指定页；另一本仍可见，便于比较 |
| 右前 | 墨水瓶、羽毛笔、裁纸刀、砂盒 | 写答卷、拆封、封信前处理墨迹 | 作为一组笔具收纳；只在有意义的步骤中单独操作 |
| 左后偏中 | 一支带刻度的蜡烛与低烛台 | 主照明、斜光检查纸张、第五幕剩余时间 | 把纸移近光源检查；刻度在第五幕成为正式行动预算 |
| 后缘靠投递口 | 浅木收发盘 | 有来路的新收件与实际递送 | 来信从投递口滑入；待寄封件放入盘中并完成交接才算送出 |
| 右侧 | 三格往来信架 | 按米兰、威尼斯、法国组织待寄信与已返回执 | 三格刻圆圈、叉、加号；将带封件编号的回执夹在对应格前 |
| 右后 | 低矮的原件封存匣 | 收纳物证与共同封存 | 放入原件、盖合、办理见证；纸封与编号呈现实际保管状态 |

这些是八个可识别的功能组，不应做成八排各自拥挤的小物品。中央至少保留约三分之一的桌面可用面积。烛台和封存匣都控制高度，不遮住纸面、笔记本或门口。

### 不必一直铺在桌上的材料

行会规程、代表登记册、检索单、空白纸、描图薄纸、替换蜡烛及已经处理的旧信，放进桌沿浅抽屉或按编号整理的卷宗。需要时取出，完成后归位。

第一幕只铺当前来信和一张工作纸。第五幕才增加三份待寄回件。不会从一开始就把所有证据和终局材料堆在桌面上。

不把紫手套摆上桌作为装饰。它在剧情中是对经手人的辨认线索，玩家尚未取得这件实物。

## 3. 用实物表示状态

| 状态 | 画面中的表现 |
|---|---|
| 有新信 | 收发盘传来轻响，一角新封袋露出；声音来自实际投递口 |
| 信已拆阅 | 蜡封破开，信纸展开；信封与正文仍可对应 |
| 草稿尚未送出 | 回信留在对应信架，没有交接回执 |
| 已实际送出 | 该封信从收发盘取走，稍后返回带编号的纸质回执 |
| 对方只确认收到 | 回执写明“已收件”，不显示成合作已经达成 |
| 对方同意参与 | 回执带具名承诺，纸上的内容可以拿起阅读 |
| 原件共同封存 | 匣子有完整见证封条、原件清单与封存编号 |
| 原件已交走 | 匣内原件不再存在，桌上留下登记交接单；已有副本继续保留 |
| 最后一小时流逝 | 刻度蜡烛按外部行动缩短；不因阅读慢或停下来思考而自行扣时 |

原稿的窗外回执板改为纸质回执。回执与其他信件走同一个投递口，归入桌上信架，不需要额外机位。

三格信架负责分类与收纳，不能仅凭“有纸”或“打了勾”判定外交承诺。判断仍依据封件编号、回执正文和签名。

## 4. 灯光与像素表现

### 三层明暗

1. **近景**：桌沿和下方保持较暗，木材边缘能读出厚度。
2. **操作区**：暖烛光落在信纸、书写垫与笔记本上，这是最高可读性的区域。纸面保留纹理，不能亮成白块。
3. **远景**：门和墙退入冷暗色，靠门缝光、木框轮廓与少量冷色环境光分开层次。

暗部要能识别物件轮廓。不能用全屏压黑、浓雾或强景深，掩盖本应可交互的物品。

### 三维与像素的分工

- 桌面、书本、烛台、门框有明确的低多边形体积，纸张通过厚度、折痕与投影区别于平面按钮。
- 环境使用低分辨率贴图、清晰的像素采样与适量色阶抖动，减少光滑写实材质。
- 可从640×360内部画面放大到1920×1080作为风格实验起点；最终以实际文字阅读测试决定采样强度。
- 密文、坐标与正文优先保证可读。纸张拉近后应能清楚辨字，不能要求玩家破解像素噪声。
- 关键物件用轮廓、位置和形状区分，颜色只作辅助。两本参考书仍须有可读的版次特征。

## 5. 少量界面的保留边界

- 默认画面不显示任务列表、背包栏、倒计时数字或全屏常驻提示。
- 可操作物件使用轻微抬角、局部反光与自然光标变化反馈，不给所有物件同时加发光描边。
- 文字输入直接显示在纸上。不得为了表现“用羽毛笔”强迫玩家逐笔描字。
- 必要的字幕、输入法、手柄文字输入与可读性选项保留。正文的阅读清晰度优先于像素化程度。
- 入场任务便笺成为放在规程册首页的实际纸张，需要时取出，不常驻屏幕角落。
